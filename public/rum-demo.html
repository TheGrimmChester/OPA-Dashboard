OPA RUM Beacon — Demo & Verification

Loads /opa-rum.js and generates realistic RUM activity (Core Web Vitals, resource & nav timing, AJAX, JS errors) so you can verify the pipeline end to end.

What this page does

  • Registers the beacon in <head> with data-debug="true" — open DevTools console to watch it work.
  • Loads images and a stylesheet to populate resource timing.
  • Fires several fetch() calls to /api/* (populates ajax_requests), including one deliberate 404.
  • Injects a late, un-sized image to produce a layout shift (CLS).
  • Buttons below let you raise an uncaught error and flush the beacon on demand.
